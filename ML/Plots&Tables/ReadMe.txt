# Plots

This folder contains the visualisations generated during the energy consumption analysis.

The plots support the results presented in the coursework report and include visualisations from:

- Exploratory and statistical analysis
- Hourly, weekly, monthly and seasonal energy patterns
- Weekday and weekend comparisons
- Correlation analysis
- Linear Regression model evaluation
- K-Means clustering
- Elbow Method and Silhouette Score analysis
- Cluster profiles and consumption distributions

The files are named descriptively so that each plot can be easily matched with the corresponding analysis in the report and Jupyter notebooks.

All plots were generated using Python from the datasets used in the coursework.
